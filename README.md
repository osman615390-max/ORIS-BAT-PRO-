## Déploiement GitHub Pages sur iPhone
Cette version est volontairement **plate** : tous les fichiers sont dans le même dossier.
1. Décompresser le ZIP
2. Sélectionner tous les fichiers
3. GitHub → Add file → Upload files
4. Mettre tout à la racine du dépôt `oris-bat-pro`
5. Commit changes
6. Settings → Pages → Deploy from branch → main / root

URL prévue :
https://osman615390-max.github.io/oris-bat-pro/
