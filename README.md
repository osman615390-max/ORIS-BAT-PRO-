# ORIS BAT PRO — VERSION IPHONE / 1 DOSSIER

Cette version est volontairement aplatie :
- AUCUN dossier assets à créer
- AUCUN fichier à déplacer
- Tous les fichiers sont dans le même dossier

## Sur iPhone
1. Décompresser le ZIP.
2. Ouvrir le dossier ORIS-BAT-PRO-IPHONE-1-DOSSIER.
3. Sélectionner TOUS les fichiers.
4. Dans le dépôt GitHub : Add file > Upload files.
5. Envoyer tous les fichiers à la RACINE du dépôt.
6. Commit changes.

Important :
- Ne pas envoyer le ZIP lui-même.
- Ne pas créer de dossier assets pour cette version.
- index.html, style.css, script.js, images SVG/WEBP : tout reste ensemble à la racine.

Formulaire devis :
- Envoi AJAX prévu vers Orisbatpro@gmail.com via FormSubmit.
- La première demande peut nécessiter la validation de l'adresse e-mail par ORIS BAT PRO.
