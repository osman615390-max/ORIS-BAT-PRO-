# ORIS BAT PRO — V5 SIGNATURE 360°

Refonte premium du site, orientée particuliers et conçue pour se différencier nettement des sites BTP classiques.

## Expériences uniques
- Studio WebGL 3D réellement rotatif à 360°
- Maison + terrain + murets + accès + mini-pelle 3D articulée
- Vues caméra par métier
- Mode Avant / Projet
- Mode Jour / Crépuscule
- Contrôle tactile iPhone et souris ordinateur
- Diagnostic chantier interactif qui transmet des critères au devis
- Intro cinématique, perspective, parallax, cartes 3D, boutons magnétiques
- Comparateur visuel chantier / projet
- Projets concept clairement identifiés comme inspirations
- Pages métiers, entreprise, zone, contact, devis, légales
- PWA, SEO, sitemap, responsive, accessibilité, réduction des animations si demandée par le système

## Studio 360°
Le moteur 3D utilise Three.js depuis jsDelivr. Si le CDN ou WebGL n’est pas disponible, le visuel photo de secours reste affiché.

## GitHub / iPhone
Tout est dans un seul dossier. Décompresser le ZIP, sélectionner tous les fichiers, les envoyer à la racine du dépôt, puis Commit changes.

## Transparence
Les visuels photo-réalistes et les projets 3D/concepts sont illustratifs. Ils ne sont pas présentés comme des chantiers réels de l’entreprise.
