## Déploiement GitHub Pages
Le dossier est volontairement **à plat** pour simplifier l'upload depuis iPhone :
1. Décompresser le ZIP.
2. Sélectionner tous les fichiers.
3. GitHub > Add file > Upload files.
4. Envoyer tous les fichiers à la racine du dépôt.
5. Commit changes.
6. Settings > Pages > main / root.
