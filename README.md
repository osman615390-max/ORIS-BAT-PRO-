# ORIS BAT PRO — V2 PARTICULIERS

Version pensée spécifiquement pour le BTP chez les particuliers.

## Direction visuelle
Noir / anthracite / blanc béton / orange chantier.
Maisons individuelles, terrains, façades et petits ouvrages : aucun positionnement "grands immeubles" et aucune mention "toute la France".

## Déploiement iPhone / GitHub
Cette version est volontairement en 1 seul dossier.
1. Décompresser le ZIP.
2. Sélectionner tous les fichiers.
3. GitHub > Add file > Upload files.
4. Envoyer tous les fichiers à la racine du dépôt.
5. Commit changes.

Aucun dossier assets à créer.

## Avant mise en ligne définitive
- Compléter l’hébergeur dans mentions-legales.html une fois le dépôt/URL final connu.
- Confirmer les certifications éventuelles avant de les afficher.
- Remplacer progressivement les illustrations par de vraies photos de chantiers si disponibles.
- Le formulaire FormSubmit peut nécessiter une confirmation de l’adresse e-mail lors du premier envoi.
